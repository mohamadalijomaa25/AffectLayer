AffectLayer Project Walkthrough

دليل مشروع AffectLayer

This document provides a comprehensive walkthrough of the AffectLayer project. It is designed to help you understand the architecture, the different AI engines, and the role of each file in the codebase so you can present it confidently.

يقدم هذا المستند جولة شاملة في مشروع AffectLayer. تم تصميمه لمساعدتك على فهم البنية، ومحركات الذكاء الاصطناعي المختلفة، ودور كل ملف في الكود المصدري حتى تتمكن من تقديمه بثقة في عرضك التقديمي.

Project Overview

AffectLayer is a dual-stack NLP (Natural Language Processing) platform designed to identify hidden emotional distress that is concealed beneath polite or neutral surface language (emotional masking).

نظرة عامة على المشروع

AffectLayer عبارة عن منصة لمعالجة اللغات الطبيعية (NLP) مزدوجة التكديس مصممة لتحديد الضيق العاطفي الخفي الذي يختبئ تحت لغة سطحية مهذبة أو محايدة (التقنيع العاطفي).

Tri-Engine Benchmarking

Instead of relying on a single AI approach, it uses a Tri-Engine Benchmarking Architecture. This means it processes text through three different NLP technologies simultaneously, allowing users to compare their strengths and weaknesses.

المعايرة باستخدام ثلاثة محركات

بدلاً من الاعتماد على نهج ذكاء اصطناعي واحد، يستخدم المشروع بنية معايرة ثلاثية المحركات. وهذا يعني أنه يعالج النص عبر ثلاث تقنيات مختلفة لمعالجة اللغات في وقت واحد، مما يسمح للمستخدمين بمقارنة نقاط القوة والضعف لكل منها بشكل مباشر.

1. Classical NLP (VADER)

A rule-based lexicon running in the Python backend. It is very fast but lacks contextual understanding (often failing to detect sarcasm).

1. المعالجة الكلاسيكية (VADER)

معجم قائم على القواعد يعمل في الواجهة الخلفية (Python). وهو سريع جداً ولكنه يفتقر إلى الفهم السياقي (غالباً ما يفشل في اكتشاف السخرية لأنها تعتمد على القواعد الحرفية).

2. Machine Learning (DistilBERT)

A Transformer-based neural network fine-tuned on the SST-2 dataset. It runs via the Hugging Face Serverless API, preventing the backend from crashing due to memory limits.

2. التعلم الآلي (DistilBERT)

شبكة عصبية تعتمد على المحولات (Transformer) تم ضبطها بدقة على مجموعة بيانات SST-2. يعمل عبر واجهة Hugging Face بدون خوادم، مما يمنع الواجهة الخلفية من التعطل بسبب قيود الذاكرة.

3. Generative AI (Gemini 2.5)

A zero-shot prompt-engineered LLM that runs directly from the client (frontend) using the Google API. It provides profound clinical reasoning and translates explanations to Arabic.

3. الذكاء الاصطناعي التوليدي (Gemini 2.5)

نموذج لغوي ضخم يعمل مباشرة من واجهة المستخدم باستخدام واجهة برمجة تطبيقات Google. يقدم تفكيراً سريرياً عميقاً ويقوم بترجمة التفسيرات إلى اللغة العربية ديناميكياً.

Codebase Structure

The project is divided into a React/Vite Frontend and a Python/FastAPI Backend.

هيكل الكود المصدري وملفات المشروع

ينقسم المشروع إلى واجهة أمامية مبنية باستخدام React/Vite وواجهة خلفية مبنية باستخدام Python/FastAPI.

Root Configuration Files

Files like package.json and vite.config.ts configure the tools used to build and run the project, like Vite (for fast builds) and Tailwind CSS (for styling without heavy frameworks).

ملفات التكوين الأساسية

تقوم ملفات مثل package.json و vite.config.ts بضبط الأدوات المستخدمة لبناء وتشغيل المشروع، مثل Vite (للبناء السريع) و Tailwind CSS (للتصميم دون الاعتماد على أطر عمل ثقيلة).

The Python Backend (backend/main.py)

This is the API server. It uses FastAPI to expose endpoints that the React frontend calls to get predictions from the Classical and ML engines.

الواجهة الخلفية (backend/main.py)

هذا هو خادم واجهة برمجة التطبيقات (API). يستخدم FastAPI لتوفير نقاط اتصال تستدعيها الواجهة الأمامية (React) للحصول على التنبؤات من المحركات الكلاسيكية ومحركات تعلم الآلة.

Python Scripts (python/)

classical_analyzer.py and ml_analyzer.py contain the logic for the VADER lexicon (custom heuristic rules) and the Hugging Face API connection for DistilBERT, respectively.

نصوص بايثون (python/)

يحتوي classical_analyzer.py و ml_analyzer.py على المنطق الخاص بمعجم VADER (قواعد مخصصة لاكتشاف التقنيع) واتصال واجهة Hugging Face لنموذج DistilBERT، على التوالي.

Evaluation Script (python/evaluation.py)

A script used to benchmark the engines against 15 clinically masked statements to show the limitations of standard ML models compared to this architecture.

نص التقييم (python/evaluation.py)

برنامج نصي يُستخدم لاختبار المحركات على 15 جملة مقنعة سريرياً لإظهار قيود نماذج التعلم الآلي القياسية مقارنة بهذه البنية المتطورة.

The React Frontend (src/)

The frontend provides the interactive user interface. Index.tsx is the main landing page arranging all visual sections like the Hero, Pipeline, and Ethics components.

الواجهة الأمامية (src/)

توفر الواجهة الأمامية واجهة مستخدم تفاعلية وجذابة. Index.tsx هي الصفحة الرئيسية التي ترتب جميع الأقسام المرئية مثل قسم العرض التقديمي (Hero) ومسار العمل والأخلاقيات.

The Core Component (Analyzer.tsx)

The most important piece of the UI. It handles user text input, selects the AI engine, makes API calls, and beautifully renders the complex results in an easy-to-read format.

المكون الأساسي (Analyzer.tsx)

أهم جزء في واجهة المستخدم. يتعامل مع إدخال النص من قبل المستخدم، ويحدد محرك الذكاء الاصطناعي، ويجري اتصالات API، ويعرض النتائج المعقدة بشكل جميل وسهل القراءة.

Key Takeaways for Presentation

AffectLayer elegantly solves the problem of detecting masked emotions by comparing three generations of AI side-by-side. It acts as an educational and research tool that visualizes the strengths and weaknesses of different NLP approaches in real-time.

النقاط الرئيسية للعرض التقديمي

يحل مشروع AffectLayer مشكلة اكتشاف المشاعر المقنعة ببراعة من خلال مقارنة ثلاثة أجيال من الذكاء الاصطناعي جنباً إلى جنب. ويعمل كأداة بحثية وتعليمية تعرض نقاط القوة والضعف لمختلف مناهج معالجة اللغات الطبيعية في الوقت الفعلي.
